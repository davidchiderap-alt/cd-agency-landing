# CD Agency Landing Page

A premium, fully responsive landing page for CD—a high-end web design and digital branding agency.

## 🚀 Live Site

Visit the live site at:
**https://davidchiderap-alt.github.io/cd-agency-landing/**

## ✨ Features

- **Ultra-modern design** with glassmorphism, smooth gradients, and micro-interactions
- **Fully responsive** — Mobile-first, scales seamlessly to 4K desktop
- **Production-ready** — Clean, semantic HTML5 with embedded CSS and vanilla JavaScript
- **High-converting UI** — Dark theme with violet/emerald accents, premium typography (Inter)

## 📋 Sections Included

1. **Sticky Navigation Bar** — Glassmorphic header with mobile hamburger menu
2. **Hero Section** — High-impact headline with dual CTAs and floating stats card
3. **Trust Badges** — Partner logos and social proof
4. **Services** — 3-column grid: Custom Web Design, E-Commerce, UI/UX Strategy
5. **Portfolio** — Featured client projects with case study links
6. **Testimonials** — Sliding carousel with client quotes, avatars, and 5-star ratings
7. **Pricing** — Three-tier pricing: Starter, Growth (most popular), Scale
8. **CTA Banner** — Bold full-width call-to-action
9. **Footer** — Multi-column layout with newsletter signup and social links

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Tailwind CSS via CDN + custom styles
- **JavaScript (Vanilla)** — Mobile menu toggle, testimonial carousel, newsletter form

## 🎨 Design Highlights

- **Glassmorphism** — Blurred glass-effect cards with subtle borders
- **Color Palette**:
  - Background: Dark navy (#07111f, #0d1728)
  - Accent: Violet (#7c5cff)
  - Secondary: Emerald (#23d5ab)
  - Text: Soft white (#f5f7ff)
- **Animations**: Smooth hover effects, card lift-up on hover, auto-rotating testimonials
- **Typography**: Inter font family with bold headlines and elegant body text
